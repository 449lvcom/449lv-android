# تطبيق 449LV أندرويد (APK مجاني)

تطبيق أندرويد بسيط يفتح `https://449lv.com/app` داخل WebView، مع الكاميرا والميكروفون لمكالمات Jitsi. **يُبنى مجاناً** على GitHub Actions ويمكن تثبيته مباشرة كملف APK **بدون متجر وبدون أي اشتراك**.

## كيف تحصل على الـ APK (خطوات سريعة)
1. ادفع هذا المجلد إلى مستودع GitHub **عام** لديك (سماء canCI/الشيكات مجانية للمستودعات العامة).
2. افتح تبويب **Actions** ← سير العمل "Build 449LV APK" سيشتغل تلقائياً (أو اضغط Run workflow يدوياً).
3. بعد انتهاء البناء، حمّل الملف من **Artifacts** باسم `449lv-apk` (المسار الظاهر: `app-debug.apk`).
4. انقل الملف إلى هاتفك الأندرويد واضغط عليه → اسمح بتثبيت التطبيقات من هذا المصدر (الإعداد يُفتح تلقائياً إن لزم) → **التطبيق يُثبَّت ويعمل**.

## ملاحظات
- الـ APK الناتج مفعّل التوقيع بأداة التطوير (debug-signed) — يكفي تماماً للاستخدام الشخصي والتثبيت المباشر.
- تسجيل الدخول بـ Google يعمل داخل التطبيق (متصفح مدمج يحفظ دخولك).
- لأي تعديل مستقبلي: عدّل `MainActivity.java` وأعد البناء — يظهر بناء جديد خلال دقائق.

## إلحاق المتجر (لاحقاً وبشكل اختياري)
- **متجر بلاي**: دفع 25$ مرة واحدة (تسجيل مطوّر) + `gradle bundleRelease` بدل `assembleDebug` لرفع AAB، مع توقيع release بمفتاحك الخاص.
- **الآيفون App Store**: يحتاج حساب Apple 99$/سنوياً (انظر مجلد 449lv-ios-app).

## محتويات المجلد
- `.github/workflows/build-apk.yml` — سير البناء المجاني (Java 17 + Gradle على خادم GitHub).
- `app/src/main/java/.../MainActivity.java` — كود WebView (تحميل الموقع + زر الرجوع + الكوكيز).
- `app/src/main/res/mipmap-*/ic_launcher.png` — أيقونات (استبدلها بأيقونتك النهائية إن رغبت).
